## 0. 命令覆盖台账（0.17.0 起）

引擎 LUT 347 条 = **真实现 139 条 + 桩 198 条**，另有 9 条 LUT 里已删的老命令也有桩。
桩都在 `src/onsmcp/stubs.py`，一条一个 `cmd_xxx`，
docstring 写语义/参数/为什么不实现/对应引擎 handler。

拿到新游戏先跑：

```bash
python tools/missing_commands.py <游戏目录>
```

- **桩** 一栏 = 引擎认识、我们没做 → 就是"要补的活"清单；
- **未处理** 一栏 = 连引擎 LUT 都没有 → 多半是定义在别的脚本文件里的宏，或脚本本身写错了
  （万华镜就有一条 `char1` 和一条 `overlap_long`，原引擎同样会报不支持）。

补的顺序：流程类命令（`break` / `tablegoto` / `skip` / `loadgosub`）已在 0.18.0 实现，
`docs/quirks.md` 里有它们的引擎规则与真引擎实测数据；剩下的桩都是"少个效果"
（特效/音频/系统菜单/二号精灵层），按新游戏实际用到的补即可。
运行时想看撞到了哪些：`state()["stubbed"]`（和"查无此命令"的 `unsupported` 分账）。

## 2. 音频与精灵（**已部分完成**）

0.9.0 已经把音频改成"记账"（不播放）并写进存档，画面状态（blt/bgcopy/帧号）也已进存档。

| 项 | 结论 |
|---|---|
| 音频解码与播放 | 不做 —— agent 听不到，存档只需要"在放什么"这个状态 |
| **所有定时器类演出**（`bg` 渐变、`cell` 自动播放、逐字显示、`quake` 抖动） | **不做**（2026-10-26 用户拍板）。agent 看不了动态内容，一律直接给终态：`bg "x",10,800` 的渐变参数忽略、条图停在指定帧、没有逐字显示 |
| 连发动画（`bg …:click` 翻页式 CG/ED） | **整段一步跳过**（有意）。万华镜 73 段 / 992 帧，逐帧等点击要按几百次；`click` 按 no-op 处理，只记进 `stubbed` 便于统计。护栏测试见 `test_bg_click_flipbook_runs_in_one_step` |
| 原版 `save<N>.dat` 互通 | **已完成**（0.11.0 读写、0.12.0 只留这一套），细节见 M / N 组 |

## 5. 已知盲区（暂时无解）

| 项 | 说明 |
|---|---|
| `nscript.___` | 这种加密格式要用游戏 EXE 里的 key table 解密，本引擎不支持；换 `0.txt` 或 `nscript.dat` |
| NBZ 压缩 | 只有解压代码，没有实测素材验证 |
